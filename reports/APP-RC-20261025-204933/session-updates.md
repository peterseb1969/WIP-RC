## 2026-10-26 22:29 — I misled Peter on the Anthropic key: optional from_secret is never injected
I told Peter that putting the key in ~/.wip-deploy/<deployment>/secrets/anthropic-api-key and redeploying would set ANTHROPIC_API_KEY, based only on RC's manifest. That was wrong, and I hadn't checked the deployer. collect_required_secrets (deployer/src/wip_deploy/secrets.py:232) scans spec.env.required only. ensure_secrets loads just those names and the renderer passes them as collected_secrets (compose.py:117), so env.py silently drops any OPTIONAL from_secret var, file or no file. Every app declares ANTHROPIC_API_KEY optional (RC, KB, AA, Cooking, VAL, dnd, song, dev-kb), so none receives it; pbs-clintrial avoids this with ANTHROPIC_API_KEY_FILE. Platform deployer bug: a case to BE-YAC was offered to Peter, not yet filed. Dev workaround: ANTHROPIC_API_KEY in RC's .env (server does import 'dotenv/config' with cwd /app = the bind-mounted repo); not yet verified end to end. Lesson: before telling the user how a platform mechanism behaves, read the code that implements it, not the declaration that names it.
